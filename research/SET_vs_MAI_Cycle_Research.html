Thesis — สมมติฐานการลงทุน

สิ่งที่เห็น: ราคา MAI ยังอยู่ใกล้ก้น ในขณะที่ SET ฟื้นไปแล้วเกือบครึ่ง · สิ่งที่ได้ถ้าถูก: ถ้า MAI ตามประวัติ จะวิ่งแรงกว่า SET หลายเท่า · สิ่งที่ต้องเป็นจริง: กำไรของกระดาน MAI ต้องหยุดตก + มี catalyst ทำให้เงินหมุนกลับมาหุ้นเล็ก · ความไม่สมมาตร: ราคาอยู่ใกล้ก้น = ระยะขาขึ้นยาวกว่าขาลงที่เหลือ แต่ต้องรอสัญญาณยืนยันก่อนเข้า

1

ภาพใหญ่: สองกระดาน สองเส้นทาง

ก่อนจะพูดถึงจังหวะลงทุน เราต้องเข้าใจก่อนว่าตลาดหุ้นไทยมีสองกระดานที่ทำงานคนละแบบ การที่คุณเห็น "ตลาดหุ้นไทยฟื้นแล้ว" อาจไม่ได้หมายความว่าทุกกระดานฟื้นเหมือนกัน

1.1 SET (กระดานหลัก) คืออะไร

SET คือตลาดหลักของไทย บริษัทใหญ่ๆ ที่เราคุ้นเคย เช่น PTT, AOT, KBANK, CPALL อยู่ที่นี่ บริษัทมักมีขนาดใหญ่ กำไรมั่นคง สภาพคล่องสูง นักลงทุนต่างชาติและกองทุนใหญ่เข้าซื้อขายที่นี่เป็นหลัก

ลักษณะเด่น: มูลค่าตลาดรวม ~20.5 ล้านล้านบาท · P/E ~17.2 เท่า · เป็นที่ที่เงิน "หลัก" ของตลาดอยู่

1.2 MAI (กระดานเล็ก) คืออะไร

MAI ย่อมาจาก Market for Alternative Investment เป็นกระดานสำหรับบริษัทขนาดเล็กและ SME (วิสาหกิจขนาดกลางและขนาดย่อม) เกณฑ์เข้าจดทะเบียนง่ายกว่า บริษัทมักเล็ก กำไรผันผวนสูง สภาพคล่องต่ำกว่า

ลักษณะเด่น: มูลค่าตลาดรวม ~219 พันล้านบาท (เล็กกว่า SET ~93 เท่า) · P/E ~69.7 เท่า (ดูแพง แต่หลอก — เหตุผลใน §4) · เป็นที่ที่เงิน "เก็งกำไร" และหุ้นเติบโตสูงอยู่

1.3 สถานการณ์ปัจจุบัน (กรกฎาคม 2026)

นี่คือภาพกราฟรายเดือนของทั้งสองกระดาน — สิ่งที่คุณเห็นคือ ความแตกแยกที่ชัดเจน

กราฟรายเดือน SET Index · SET · สีแดง = ราคาปัจจุบัน ~1,621 · ฟื้นจากก้น 1,090 (มิ.ย. 2025)

นี่คือหัวใจของงานวิจัยนี้ — เรามาดูว่าในอดีต SET กับ MAI เคลื่อนตัวเทียบกันยังไง และหา แพทเทิร์น ที่ซ้ำกัน

เฟส 1: ตกพร้อมกัน แต่ MAI ตกหนักกว่า (2019-2020)

ช่วง COVID-19 ทั้งสองกระดานตก แต่ MAI ตกแรงกว่าเพราะบริษัทเล็กทนแรงกระแทกได้น้อยกว่า SET ตก -8.3% ในขณะที่ MAI ตก -22.5% — เมื่อรวม 2 ปี MAI ตก -37% สะสม ต่อจากนั้นคือจุดเริ่มต้นของการระเบิด

เฟส 2: การระเบิดของ MAI (2020-2022) — จุดสำคัญที่สุด

นี่คือช่วงที่ MAI สร้างผลตอบแทนมหาศาล: จาก 240 จุดขึ้นไป 660 จุด = +175% ใน 2 ปี เทียบกับ SET ที่ทำแค่ +15%

MAI outperform SET ถึง +160 จุด — คือถ้าคุณลงทุนในหุ้น MAI ที่ถูกตัวเดียวกับที่เราจะวิเคราะห์ต่อไป คุณจะทำกำไรมากกว่า SET หลายเท่า

เงื่อนไขที่ทำให้ MAI ระเบิด:

  • ราคาอยู่ใกล้ก้นมาก (P/B ต่ำ) ก่อนเริ่ม rally
  • เศรษฐกิจเริ่มฟื้นจาก COVID (GDP +1.6% ใน 2021)
  • กำไรของบริษัทเล็กกลับมาโตแรง (auto parts, oil price recovery)
  • นักลงทุนต่างชาติกลับเข้าซื้อหุ้นไทย (+35.5% YoY ส.ค. 2021)
  • สภาพคล่องกลับเข้ามา

เฟส 3: ตกอีกครั้ง MAI ตกหนักกว่าอีก (2022-2025)

จากพีก 660 จุด MAI ตกลงไปที่ก้น 209 = -68% ใน 3 ปี ส่วน SET ตกจาก 1,669 ไป 1,090 = -35% MAI ตกหนักกว่า SET อีกครั้ง -34 จุด — แพทเทิร์นเดิม: กระดานเล็กตกหนักกว่าเสมอเวลาตลาดเป็นขาลง

เฟส 4: SET ฟื้นก่อน MAI ยังไม่ตาม (2025-ปัจจุบัน)

นี่คือจังหวะที่เราอยู่ตอนนี้: ตั้งแต่ก้น มิ.ย. 2025 SET ฟื้นไปแล้ว +49% (1,090 → 1,622) แต่ MAI ยังอยู่ที่ +8% เท่านั้น (209 → 226)

จากประวัติ: SET ฟื้นก่อนเสมอ → MAI ตามมาทีหลัง ในรอบ 2020 SET เริ่มฟื้นก่อนประมาณ 6-9 เดือน แล้ว MAI จึงเริ่มวิ่งแรง → เราอาจอยู่ใกล้จุดนั้นแล้ว

2.3 บทเรียนสำคัญจากวัฏจักร

บทเรียนหลักฐานจากข้อมูลความหมายต่อการลงทุน
1. SET ฟื้นก่อนเสมอทุกรอบ SET นำ MAI 6-12 เดือนเมื่อ SET ฟื้น ให้เริ่มเตรียมดู MAI
2. MAI ตกหนักกว่าเวลาขาลง2022-2025: MAI -68% vs SET -35%อย่าถือหุ้น MAI ในขาลงโดยไม่มี stop
3. MAI วิ่งแรงกว่าเวลาขาขึ้น2020-2022: MAI +175% vs SET +15%รอบฟื้นตัวของ MAI ให้ผลตอบแทนสูงกว่ามาก
4. กำไรเป็นตัวขับหลักหุ้นที่พุ่งคือหุ้นที่กำไรโต +1,000%+หุ้น MAI ไม่ได้พุ่งเพราะ multiple แต่เพราะกำไรจริง
5. P/B ต่ำ = จุดเริ่มต้น rallyก่อน 2020 MAI P/B ต่ำ → แล้ว rallyP/B 1.15 ปัจจุบัน = สัญญาณเดียวกัน

4

Valuation: ทำไม P/E หลอก และ P/B บอกความจริง

ตอนที่คุณพยายามดึง EPS TTM (กำไรต่อหุ้นย้อนหลัง 12 เดือน) มาแปะบนกราฟ คุณกำลังทำสิ่งที่ถูกต้อง — เพราะต้องดูว่าราคาที่ตกไปนั้นเกิดจากอะไร แต่มีเรื่องสำคัญที่ต้องเข้าใจ

4.1 P/E 69.7 เท่าของ MAI หลอกตรงไหน?

P/E (ราคาต่อกำไร) คำนวณจาก ราคา ÷ กำไรต่อหุ้น ปกติ P/E สูง = แพง แต่ของ MAI ที่ 69.7 เท่านั้น หลอก

เหตุผล: ใน MAI มีบริษัทจำนวนมากที่ ขาดทุน เมื่อบริษัทขาดทุน กำไรต่อหุ้นจะเป็นลบหรือใกล้ศูนย์ พอตัวหาร (กำไร) เล็กมาก P/E จะกลายเป็นเลขใหญ่ผิดปกติ

เปรียบเทียบ: ถ้าบริษัท A ราคา 10 บาท กำไร 1 บาท → P/E = 10 เท่า (ปกติ) แต่ถ้าบริษัท B ราคา 10 บาท กำไร 0.14 บาท → P/E = 69 เท่า (ดูแพง แต่จริงๆ คือกำไรมันน้อยมาก)

4.2 P/B 1.15 เท่าบอกอะไร

P/B (ราคาต่อมูลค่าทางบัญชี) คือราคาที่คุณจ่ายเทียบกับมูลค่าทรัพย์สินสุทธิของบริษัท P/B 1.15 หมายความว่าคุณจ่ายเกินมูลค่าทางบัญชีแค่ 15% — ซื้อของเกือบตามราคาทุน

ข้อสังเกตสำคัญ: P/B 1.15 ของ MAI อยู่ใกล้ระดับต่ำสุดทางประวัติศาสตร์ และใกล้เคียงกับระดับที่ MAI อยู่ ก่อนเริ่ม rally ปี 2020-2022 — นี่คือสัญญาณว่ากระดานเล็กอาจอยู่ในจุดที่ "ถูกพอที่จะเริ่มระเบิดได้" ถ้ามี catalyst

4.3 EPS หลายมุม — ดูทั้ง 3 ทางพร้อมกัน

เพื่อให้เข้าใจกำไรของ MAI จริงๆ เราต้องดูหลายมุมพร้อมกัน:

มุมมองตัวเลขวิธีอ่านน่าเชื่อถือ?
P/E (ดูจากกำไร) 69.7× ดูแพง แต่หลอกเพราะบริษัทขาดทุนเยอะทำให้ตัวหารเล็ก ไม่เชื่อถือ
P/B (ดูจากทรัพย์สิน) 1.15× ถูกแล้วระดับ book value ใกล้ประวัติต่ำ เชื่อถือที่สุด
Index EPS (กำไรต่อหุ้นรวม) 3.24 ตกจากพีกมาก แต่ถ้าหยุดตก = ราคาพร้อมฟื้น ดูทิศทาง

Insight สำคัญ: คุณไม่ควรใช้ P/E ของ MAI เป็นตัวตัดสินใจว่า "แพงหรือถูก" เพราะมันหลอก ให้ใช้ P/B + ทิศทางกำไร แทน การที่ P/B อยู่ที่ 1.15 และกำไรยังไม่ยืนยันว่าหยุดตก แปลว่า "ถูกแล้ว แต่ยังรอกำไรกลับมา" — นี่คือสภาพ deep value ที่รอ catalyst

ระบบสแกนหุ้นจากประวัติ — เกณฑ์คัดกรอง

จากทุกสิ่งที่เราศึกษามา นี่คือ ระบบคัดกรองหุ้น (Screening Framework) ที่นักลงทุนสามารถนำไปใช้เพื่อหาหุ้น MAI ที่จะนำการฟื้นตัวรอบต่อไป — ออกแบบจากแพทเทิร์นของ FPI, SEAOIL, BIZ, TRT ที่เคยเป็นผู้นำ

เกณฑ์ 5 ข้อ (Screening Checklist)

#เกณฑ์ค่าเป้าหมายทำไมสำคัญ
1 P/B ต่ำ < 1.5× ซื้อใกล้มูลค่าทางบัญชี = ความเสี่ยงจำกัด ตามแพทเทิร์น FPI/SEAOIL ก่อน rally
2 กำไรกำลังหันขึ้น YoY > 0 จุดเข้าคือตอนกำไรเปลี่ยนจากลงเป็นขึ้น — นี่คือตัวขับราคาจริง
3 Cyclical + Export-exposed — ผู้นำ 2021 ทุกตัวขึ้นกับวัฏจักรโลก ไม่ใช่ domestic pure-play
4 Market cap เล็ก ฿1-5B เล็กพอที่จะพุ่งได้หลายเท่า แต่ใหญ่พอที่จะไม่ใช่ penny stock
5 ROE ยังดี > 8% บริษัทต้องยังทำกำไรจากทุนได้ ไม่ใช่ขาดทุนเรื้อรังเหมือน RWI

วิธีใช้ระบบนี้

ขั้นที่ 1: กรองด้วย P/B

สแกนหุ้น MAI ทั้งหมดที่ P/B < 1.5 เท่า — นี่จะตัดบริษัทที่ "แพง" ออก เหลือแต่ของถูก

ขั้นที่ 2: เช็กกำไร

จากที่เหลือ ดูว่ากำไรไตรมาสล่าสุดเทียบกับปีก่อน "หยุดตกหรือเริ่มขึ้น" หรือไม่

ขั้นที่ 3: เช็กธุรกิจ

เลือกเฉพาะที่เป็น cyclical + export — ตัด domestic pure-play ที่ไม่เคยเป็นผู้นำออก

ขั้นที่ 4: เช็กความสมเหตุสมผล

เอาที่เหลือมาวิเคราะห์เชิงลึก — อ่านงบการเงิน เช็ก ROE, หนี้สิน, กระแสเงินสด

ตัวอย่างการประยุกต์ใช้

จากข้อมูลที่เรามี: FPI (P/B 0.86, ROE 10.3%) ผ่านเกณฑ์ที่ 1, 4, 5 แต่ยังไม่ผ่านเกณฑ์ที่ 2 (กำไรยังไม่ระเบิด) และเกณฑ์ที่ 3 (auto parts ยังรอ recovery) → อยู่ในระยะเฝ้าระวัง ยังไม่ถึงจุดเข้า

BIZ (P/B 3.34, ROE 38%) ผ่านเกณฑ์ที่ 2, 4, 5 แต่ไม่ผ่านเกณฑ์ที่ 1 (P/B สูง) → ฟื้นตัวแล้ว ไม่ใช่ deep value setup

→ ระบบนี้ช่วยให้นักลงทุนแยกแยะได้ว่าหุ้นไหน "ถูกและกำลังจะระเบิด" vs "ถูกแต่ยังไม่มีอะไรมาขับ" vs "แพงแล้วฟื้นตัวแล้ว"

Verdict — คำตัดสินตอนนี้

ยังไม่ถึงเวลาเข้า MAI แบบเต็มสูตร — ราคาถูกแล้ว (P/B 1.15) แต่ยังไม่มีสัญญาณยืนยันว่ากำไรจะกลับมา นักลงทุนควร:

  1. เตรียมระบบสแกน — ใช้เกณฑ์ 5 ข้อใน §6 เพื่อหาหุ้นที่จะนำรอบต่อไป
  2. เฝ้าระวัง 5 สัญญาณ — โดยเฉพาะ EPS หยุดตก + สภาพคล่องเพิ่ม
  3. เริ่มต้นด้วยการวิเคราะห์หุ้นเดี่ยว — ไม่ใช่ซื้อทั้งกระดาน เพราะแม้ในกลุ่มผู้นำเก่าก็มีทั้งฟื้นแล้ว (TRT, BIZ) และยังไม่ฟื้น (RWI)
  4. จัดสรรความเสี่ยง — Medium risk / 1 ปี = อย่าลงน้ำหนักมากจนกว่าจะมีสัญญาณยืนยัน

ข้อเสี่ยงทิศทางระดับผลกระทบวิธีเช็ก
กำไร MAI ไม่หยุดตก ถ้า EPS ยังลง = ราคาจะลงตาม สูงมาก เช็ก EPS รายไตรมาส

SME ปิดตัวต่อเนื่อง ถ้าปิดตัวเพิ่ม = บริษัทจดทะเบียนลด กลาง ดูสถิติปิดกิจการรายปี
สภาพคล่องต่ำต่อเนื่อง ถ้าไม่มีเงินเข้า = ราคาไม่วิ่ง กลาง ดู turnover ratio MAI
เงินไหลไป SET ไม่หมุนมา MAI ถ้า SET ยังดึงดูดเงินทั้งหมด = MAI ไม่ตาม กลาง ดู foreign flow รายเดือน
Catalyst ไม่มา ถ้าไม่มีเหตุการณ์ขับ = อาจติดอยู่ใน low P/B นาน กลาง ดูข่าวเศรษฐกิจ/นโยบาย

ความเสี่ยงใหญ่ที่สุด: หุ้นถูกแต่ไม่มี catalyst ทำให้ราคาขึ้น — นี่คือ "value trap" ที่นักลงทุนหุ้นเล็กเจอบ่อย การมี P/B ต่ำไม่ได้แปลว่าราคาจะขึ้น ต้องมีกำไรกลับมาด้วย ระบบสแกนใน §6 ออกแบบมาเพื่อหลีกเลี่ยงกับดักนี้โดยเน้นเกณฑ์ที่ 2 (กำไรหันขึ้น)

ศัพท์ความหมายแบบเข้าใจง่าย
P/E (Price/Earnings)ราคาหุ้น ÷ กำไรต่อหุ้น — บอกว่าจ่ายกี่เท่าของกำไรเพื่อซื้อหุ้น ต่ำ = ถูก
P/B (Price/Book)ราคาหุ้น ÷ มูลค่าทางบัญชีต่อหุ้น — บอกว่าจ่ายกี่เท่าของทรัพย์สินสุทธิ ต่ำ = ถูก
EPS (Earnings Per Share)กำไรต่อหุ้น — กำไรที่บริษัททำได้ต่อหุ้น 1 ตัว
ROE (Return on Equity)กำไรต่อส่วนของผู้ถือหุ้น — บอกว่าบริษัทใช้เงินทุนสร้างกำไรได้ดีแค่ไหน สูง = ดี
