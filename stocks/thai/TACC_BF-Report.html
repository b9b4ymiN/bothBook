บทสรุปผู้บริหาร

ข้อมูลเชิงลึกการลงทุนหลัก · Key Investment Insight

TACC คือธุรกิจ “ขายจอบขายเสียม” ให้ระบบ 7-Eleven ที่ใช้เงินลงทุนต่ำมาก — ทำ ROE ~40% บนสินทรัพย์ถาวรเพียง ฿156 ล้าน ต่อยอดขาย ฿2,399 ล้าน ไม่มีหนี้ และจ่ายปันผล ~85% ของกำไร (yield ~7%) — แต่จุดแข็งนี้คือจุดเปราะเดียวกัน

รายได้และกำไร กว่า 90% มาจากลูกค้ารายเดียว (CP All/7-Eleven) และเป็นการโตแบบ “เช่ามา ไม่ได้เป็นเจ้าของ” ที่กดมาร์จิ้น: 5 ปีที่ผ่านมา ยอดขายโต 15.7%/ปี แต่กำไรสุทธิโตเพียง 8.7%/ปี เพราะอัตรากำไรขั้นต้นลดจาก 38%→32%. มูลค่าเหมาะสม ~฿7.0 (กรอบ ฿6.5–7.5) เทียบราคา ฿5.80 → upside ~20% + ปันผล ~7% — ทั้ง “เพดาน” และ “พื้น” ของหุ้นถูกกำหนดโดย 7-Eleven. ส่วนต่างจะปิดได้ก็ต่อเมื่อ B2C/ลิขสิทธิ์/ต่างประเทศพิสูจน์ว่าลดการพึ่งพาได้จริง และมาร์จิ้นหยุดหด.

Thesis การลงทุน

จ่ายราว 11.8 เท่าของกำไร (ปันผล ~7%) เพื่อซื้อ “เครื่องผลิตเงินสด” คุณภาพสูง — ROE ~40%, สถานะเงินสดสุทธิ, FCF แข็ง — ที่เกาะการเติบโตของเครือข่าย 7-Eleven โดยแทบไม่ต้องลงทุนเอง. สิ่งที่ต้องเป็นจริง: 7-Eleven ขยายสาขา/ทราฟฟิกต่อเนื่อง, กระแสชาไทย–ชาเขียวไม่แผ่ว, และอัตรากำไรหยุดหด (หรือ B2C มาร์จิ้นสูงเข้ามาพยุง). ความไม่สมมาตร: upside ~20% ด้านราคา + 7% ปันผล เทียบกับ downside ~15% หากเกิด concentration shock — เอียงไปทางบวกเล็กน้อย แต่ถูกจำกัดด้วยเพดานของพันธมิตรรายเดียว.

คำถามนักลงทุน 5 ข้อ — คำตอบโดยสรุป

คำถามคำตอบ (อิงข้อมูลจริง)สรุป
1. ร่วมกับพันธมิตรพัฒนาผลิตภัณฑ์จริงไหม? จริง และเป็นหัวใจของธุรกิจ. TACC “ร่วมพัฒนาสูตร/สินค้า” กับ CP All โดยตรง — เครื่องดื่มโถกด (เอสเปรสโซ/ลาเต้/ชาเย็น), ผงชงสำหรับ All Café, สินค้าตามฤดูกาล (ชาพีช, น้ำผึ้งมะนาว, Pinky Candy), เครื่องกดเครื่องดื่มร้อน + มี R&D ของตัวเอง และสิทธิ์คาแรคเตอร์ (San-X/Rilakkuma, ปังปอนด์ ฯลฯ) จริง
2. รายได้เพิ่มเพราะยอดขายเครื่องดื่มใน 7-Eleven จริงไหม? จริง. บริษัทระบุเองว่าการเติบโตปี 2568 (+22.8%) มาจาก “ยอดขายสินค้าในร้าน 7-Eleven ที่เพิ่มขึ้น” (วอลุ่มบริโภคในประเทศ + กระแสชาไทย/ชาเขียว) บวกสินค้าใหม่ที่ร่วมพัฒนา. ไตรมาส 1/2569 ยอดขาย +20.5%, กำไร +36.3% จากชาไทย/ชาเขียว จริง
3. โตจาก reinvestment คุณภาพสูง หรือโตจากการขยายกับพันธมิตรโดยใช้เงินลงทุนต่ำ? ทั้งสองอย่าง — แต่เป็น “แบบหลัง” เป็นหลัก. ผลตอบแทนต่อทุนสูงมาก (ROE ~40%, ROIC ~50%) = คุณภาพสูง; แต่บริษัทลงทุนเอง “น้อยมาก” (capex ~฿40 ล้าน/ปี, PP&E = 6.5% ของยอดขาย, จ่ายปันผล ~85%). การเติบโตหลักมาจาก “เกาะ” เครือข่าย 7-Eleven + สินค้าใหม่ + เทรนด์ชา ไม่ใช่ทุ่มเงินลงทุนสร้างสินทรัพย์เอง capital-light / partner-led
4. กำไรมาจาก Core B2B จริงไหม? จริงและชัดเจน. B2B ~90–91% ของรายได้ (เกือบทั้งหมดคือขายให้ 7-Eleven), B2C ~9% (ณ อรุณ, TRIVA, ลิขสิทธิ์), อื่นๆ <1%. แม้ B2C โตเร็วกว่าและมาร์จิ้นสูงกว่า แต่ฐานเล็ก → กำไรส่วนใหญ่ยังมาจาก Core B2B จริง ~90%
5. ถ้าเป็น Core B2B ส่งผลกับหุ้นอย่างไร? เป็นดาบสองคม: (ก) ความเสี่ยงกระจุกลูกค้ารายเดียว (CP All >90% — บริษัทระบุเป็นความเสี่ยงอันดับ 1); (ข) สเกล B2B กดมาร์จิ้น → กำไรโตช้ากว่ายอดขาย; (ค) เพดานการเติบโตผูกกับ 7-Eleven; (ง) แต่คุณภาพการเงินสูง + ปันผล ~7% ทำให้หุ้นเป็น “dividend compounder” มากกว่าหุ้นโตแรง → ตลาดให้ส่วนลด (P/E 11.8x) สวนคุณภาพ ROE discount เพราะ concentration

1.1 โมเดลธุรกิจและโครงสร้างรายได้

TACC ทำเงินจากการ “ร่วมพัฒนาสูตร/ผลิตภัณฑ์” กับ CP All แล้วผลิต (ทั้งโรงงานตัวเองและจ้าง OEM) ส่งขายผ่านเครือข่ายร้าน 7-Eleven กว่า 15,000 สาขา. กำไรกระจุกที่ B2B จริง — และนั่นคือทั้งจุดแข็งและจุดเสี่ยงของหุ้น. (โครงสร้างปี 2567 ซึ่งเป็นปีล่าสุดที่บริษัทแยกสัดส่วนชัดเจน)

1.2 ความได้เปรียบเชิงแข่งขัน (Moat)

switching cost (สองทาง) scale ของพันธมิตร R&D / speed-to-shelf character license — moat แบบ “ความสัมพันธ์ + ความเร็ว” มากกว่าแบรนด์ผู้บริโภค

Narrow (แคบ) ความทนทาน: ทรงตัว แต่ผูกกับลูกค้ารายเดียว ROIC−WACC ≈ +40pp

หลักฐานของ moat: incumbency >20 ปีกับ CP All, R&D ที่ออกสินค้าใหม่/ตามฤดูกาลได้เร็ว, และส่วนต่าง ROIC−WACC ที่กว้างมาก (ผลตอบแทนต่อทุน ~50% สูงกว่าต้นทุนเงินทุน ~10% มาก) — พิสูจน์ว่ามี “เศรษฐศาสตร์เฉพาะตัว” จริง. แต่เป็น moat แบบ แคบ เพราะอำนาจต่อรองและการกำหนดราคาอยู่ที่ CP All. ภัยคุกคามอันดับ 1: CP All เปลี่ยนเงื่อนไข ผลิตเอง (in-source) หรือให้คู่แข่งเข้ามาแบ่งหมวดสินค้า.

1.3 อุตสาหกรรมและ TAM

ตลาดเครื่องดื่มชา/กาแฟพร้อมดื่มและในร้านสะดวกซื้อของไทยยังโตตามการบริโภคและกระแส “ชาไทย/ชาเขียว” (soft power). ตัวขับเคลื่อนหลักของ TACC คือการขยายตัวของ 7-Eleven เอง: CP All ปี 2568 รายได้ ~฿462,854 ล้าน กำไร ~฿24,984 ล้าน และยังเปิดสาขาเพิ่มต่อเนื่อง — ยิ่งสาขา/ทราฟฟิกมาก ฐานขายของ TACC ยิ่งกว้าง. การแข่งขันในชั้นวาง RTD สูง (Ichitan, Oishi, Sappe) แต่ช่อง “โถกด + ผงชง All Café” เป็นพื้นที่กึ่งผูกขาดที่ TACC ครอง. TAM ขยายตามจำนวนสาขา + การเพิ่มเมนู/หมวดใหม่ + การรุก B2C/ต่างประเทศ (กัมพูชา, มาเลเซีย ฯลฯ).

1.4 การเติบโตและคุณภาพการลงทุนซ้ำ

การเติบโตมาจาก (1) จำนวนสาขา/ทราฟฟิกของ 7-Eleven, (2) สินค้าใหม่ร่วมพัฒนา + เมนูตามฤดูกาล, (3) เทรนด์ชาไทย/ชาเขียว, (4) B2C/ลิขสิทธิ์/ต่างประเทศ (ฐานเล็กแต่มาร์จิ้น/โตสูงกว่า). คุณภาพการลงทุนซ้ำ: ผลตอบแทนสูงกว่า WACC มาก (สร้างมูลค่า) — แต่ “ปริมาณ” การลงทุนต่ำ: capex ~฿40 ล้าน/ปี, จ่ายปันผล ~85% ของกำไร, และเงินลงทุนที่เพิ่มส่วนใหญ่เป็น เงินทุนหมุนเวียน (ลูกหนี้การค้า CP All + สต๊อก) ไม่ใช่สินทรัพย์ผลิตใหม่. โรงงานที่ 3 (บ้านบึง) เป็น capex ก้อนหลักเพื่อลดการพึ่ง OEM. สรุป: การโตคุณภาพสูงด้านผลตอบแทน แต่ใช้เงินลงทุนต่ำและพึ่งเครือข่ายของพันธมิตร ดู §2 และ §3

1.5 วัฏจักรธุรกิจและบททดสอบ 3P

Mature-growth — ธุรกิจ niche ที่ตั้งตัวแล้ว โตระดับ mid-teens ด้านยอดขาย จ่ายปันผลสูง บ่งชี้ว่า driver สำคัญคือ “วอลุ่ม × มาร์จิ้น” ไม่ใช่การลงทุนก้อนใหญ่.

Possible · Plausible · Probable

Possible: ขยาย B2C/ต่างประเทศ/ลิขสิทธิ์จนลดพึ่งพา 7-Eleven ต่ำกว่า 80% และดัน margin กลับขึ้น  ·  Plausible: โต 8–12%/ปี ตาม 7-Eleven + สินค้าใหม่ + เทรนด์ชา  ·  Probable: โต high-single ถึง low-double digit, มาร์จิ้นทรงตัวถึงหดเล็กน้อย, ปันผลสูงต่อเนื่อง

ธงเตือน “this time is different”: อย่าคาดว่ามาร์จิ้นจะกลับไป 38% หรือกำไรจะโตเท่ายอดขาย จนกว่าจะเห็น B2C มาร์จิ้นสูงสเกลได้จริง

พารามิเตอร์ที่ fit กับหุ้นนี้: เคารพโครงสร้าง higher-low รายสัปดาห์ · แนวต้านสำคัญ ฿6.0–6.05 (จุดสูงสุด 52 สัปดาห์) · แนวรับ ฿5.3 (ฐานล่างของกรอบ) และ ฿5.5 (higher-low ล่าสุด) · วอลุ่มขยายตอนขึ้น · สภาพกราฟ: ขาขึ้นรอย่อ / ชนแนวต้าน

ขนาด & การทยอย: ความเชื่อมั่นปานกลาง → ทยอย 2–3 ไม้ ไม่ overweight เพราะความเสี่ยงลูกค้ารายเดียว

สิ่งที่เพิ่มความเชื่อมั่น (เฝ้าทุกไตรมาส): สัดส่วน B2C/ลิขสิทธิ์เพิ่มขึ้น, อัตรากำไรขั้นต้นหยุดหด/ฟื้น, ยอดต่างประเทศโต, จำนวนสาขา 7-Eleven เพิ่ม
